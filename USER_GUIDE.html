Department Management System

Complete Technical Architecture Guide, Data Flow Manual & User Operations Blueprint for LJ University.

🏛️ 1. Executive Summary & Purpose

The Department Management System centralizes academic administration across all Schools, Institutes, Departments, Degree Programs, and Faculty Members at LJ University.

🏢 Academic Hierarchy

Maintains relational links between Schools $\rightarrow$ Departments $\rightarrow$ Academic Programs $\rightarrow$ Faculty Staff.

🔒 Role-Based Access

Granular permission control for Admin/Superadmin, Academic Deans, Department HODs, and Faculty.

🗓️ Academic Sessions

Contextualizes metrics and reporting across historical, active, and upcoming academic sessions.

⚡ PostgreSQL Reliability

ACID-compliant storage, connection pooling, foreign key constraints, and live query diagnostics.

🚀 8. Setup & Execution Guide

⚡ Quick Windows Launch
Double click start-all.bat in the project root to start both Frontend & Backend with a single click.

Manual Step-by-Step Commands:

# 1. Start Backend API Server
cd backend
npm install
npm run seed       # Populates PostgreSQL with realistic NUV university records
npm run dev        # Starts Express server at http://localhost:5000

# 2. Start Frontend React App (in a separate terminal)
cd frontend
npm install
npm run dev        # Launches React Vite at http://localhost:5173

🔧 10. Troubleshooting & FAQ

Error Message Probable Cause Solution

NetworkError / Failed to fetch Backend server is not running or wrong API URL Verify backend is running on port 5000 or check VITE_API_URL
