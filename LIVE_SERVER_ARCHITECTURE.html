All Cloud Systems Operational

Live Server & Deployment Architecture

Where the Frontend, Backend, and PostgreSQL Database are hosted on the internet, and how they communicate with 100% cloud decoupling.

☁️ 1. The 3 Live Cloud Hosting Environments

🌐
Presentation Tier
Frontend (React 19)

Serves the compiled single-page application (SPA) to browsers worldwide.

  • Cloud Host Vercel (Global Edge Network)
  • Technology Stack React 19 + Vite + Lucide Icons
  • Physical Deployment Distributed CDN across 100+ global edge locations
  • Environment Variable VITE_API_URL pointing to Render
⚙️
Application Tier
Backend (Express API)

Processes authentication, validates business logic, and manages REST routes.

  • Cloud Host Render.com (Web Service Container)
  • Live API URL nuv-department-api.onrender.com
  • Technology Stack Node.js + Express.js + pg Driver
  • Container Location Linux Container (Singapore Cloud Region)
🗄️
Persistence Tier
PostgreSQL Database

Provides persistent ACID storage, foreign keys, and automatic backups.

  • Cloud Host Neon.tech (Serverless PostgreSQL)
  • Database Engine PostgreSQL 16 (nuv_department_db)
  • Encrypted Connection SSL/TLS over Port 5432 (TCP)
  • Physical Datacenter AWS Asia-Pacific (Singapore Region)

🎤 3. How to Explain This in an Interview / Presentation

🗣️ Recommended Speech Script

"Our Department Management System is deployed on a fully decoupled 3-tier cloud architecture. The React frontend is hosted on Vercel's Edge CDN for fast global loading. The Express.js backend API is containerized on Render in Singapore, handling business logic and JWT authentication. All persistent university records are stored in a managed PostgreSQL cluster on Neon with encrypted SSL connection pooling. Whenever a user performs an action in the UI, an HTTPS request travels to Render, which securely queries Neon PostgreSQL and returns live data."
